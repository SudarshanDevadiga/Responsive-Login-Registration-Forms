# Responsive Login & Registration Forms

This repository contains two clean, simple, and responsive forms built using **HTML** and **CSS**:

- ✅ `login.html` – A responsive login form
- ✅ `register.html` – A responsive registration form

Both forms follow basic web design principles for accessibility, readability, and usability.

---

## 🌐 Live Demo

You can open the files directly in your browser:

- [Login Form](login.html)
- [Registration Form](register.html)

---

## 🛠 Features

- Responsive design using relative units like `rem`, `%`, and `vh/vw`
- Clean layout with accessible font sizes and spacing
- Hover effects on buttons
- Modern UI with minimal and readable styling
- Works well on mobile, tablet, and desktop screens
